# Competitive Programming
My solutions to competitive programming problems, in C++. Each folder is a platform or contest (Codeforces, Kattis, CSES, etc.) and each subfolder is a problem.

I use it to practice algorithms, data structures and problem solving, so the code favors solving within the time limit over readability.

---

Minhas soluções de problemas de programação competitiva, em C++. Cada pasta é uma plataforma ou competição (Codeforces, Kattis, CSES etc.) e cada subpasta um problema.
